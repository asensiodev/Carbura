# Eliminación de cuenta: requisito de publicación

Carbura permite solicitar la eliminación permanente desde la sección `Usuario` de la aplicación Android. Antes de distribuir una versión de producción también debe existir una página web pública desde la que una persona pueda solicitar la eliminación sin tener instalada la aplicación.

## Requisito pendiente

- Publicar una URL HTTPS estable bajo un dominio controlado por Carbura.
- Identificar claramente la aplicación y el responsable del tratamiento.
- Explicar cómo solicitar la eliminación y qué datos se eliminan o conservan.
- Indicar cualquier periodo de retención exigido legalmente.
- Configurar esa URL en la sección de seguridad de datos de Google Play Console.

La URL de producción todavía no está decidida. No debe publicarse la aplicación en Google Play hasta completar y verificar este requisito.
